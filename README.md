# AI Resume Analyzer & ATS Checker

An AI-powered resume analysis application that evaluates a resume against a job description and provides actionable feedback to improve job matching and ATS compatibility.

## 🚀 Features

- Upload and analyze resumes
- Extract important information from resume documents
- Match resume skills with job-description requirements
- Generate an ATS-style compatibility score
- Identify missing or relevant skills
- Provide suggestions for improving the resume
- Simple and user-friendly interface
- Fast analysis and structured results
